## 4. Standard

The border (frame) of the drawing should have 5 milimeters. The title block should be place in the bottom right corner of the block. Title block is 185 wide and 45 high. 

## 5. Projection

Points lying on the plane are equal in its position when projected. 

If two points lay on the projection line, the intersection of the plane and the projection line is the same for both points.

## 6. Orthogonal projection

The orthogonal projection's projection line is perpendicular to the projection plane.

## 7. Monge's projection

Monge figured out that by using two intersected, perpendicular lines, and using one, single projection line, we can represent any position of any 3-dimensional object on a 2-dimensional plane. A point A of the object is given form on the planes by A' and A''.  The Monge's projection is done by using orthogonal projection (a perpendicular projection line). Intersection of both planes where the object is projected = special point Z. 

The projection changes slightly depending on the quarter the object is positioned in. 

## 8. Solids

It's possible to represent the solids on projection planes. It's just needed to project points on planes. 

## 9. Scales, lines, planes

### Scales

ISO standards define the usable scales for the element we need to draw. There are increasing and decreasing scales. The natural scale is 1:1. 

### Lines

There are extra wide, wide and narrow lines. Wide line - soft pencil. Narrow line - hard pencil. 

There are two main types of lines: Continuous and dashed. Extra wide lines can't be used to draw any type of line besides a continuous one. 
Standard width for medium drawings is a = 0.5mm. 

ISO 128-2 defines where every type of line can be used. 

A dashed / dot-dashed line can signalize symmetry of an object.

### Planes

Sometimes, we use more than 2 or 3 planes. We can also use 6 planes, as if enclosing the object in a box.
