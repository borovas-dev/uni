## European projection

Let's imagine that the object is turned around from the central position. On the bottom, there's view from the top, on the top there's view of the bottom etc. 

The size on all the planes should be entirely proportional (heigth, width) 

## Methods

There are other views that we could use, especially when the shape of the object is complicated and difficult to represent by the european method. 

The drawing can be marked with arrows, which define the direction an object should be looked at from. 

## Sectional views

We can use a special plane (a sectional plane) that 'cuts' the element in 2 parts ( a cutting plane), so we can see a new view (a virtual object) that represents how the object is structured from the inside. 
The sectioned drawing has lines that are narrow (hatching lines) that represent a place where the object has been cut in.

Line-dotted line represents a cylindrical form of the cut (e.g. a hole) in a sectional view. 

Hatching lines are very different depending on the material we are using. 

Normally, hatching lines are in 45 degrees from the edge or the symmetrical line of a rounded, edgeless object.
If an object is placed in 45 degrees, the angle should be 30 degrees or similar (mustn't be parallel to the edges)

The direction or density can change in the case of different objects in one sectional view (if it's the same material).

The cutting plane (cross-section plane) is represented by thick lines outside of the object and arrows that show the direction a person should be looking at. Sections should be drawn with 2 letters

## Partial views

Depict only a portion of the object. A zig-zag line defines that the rest of the object is connected to the zig-zag line.

Partial views can be scaled to inform about the proper information about a very small part of an object

## Auxiliary views

They depict surfaces of objects that aren't parallel to the projection plane. It's used when an object is inside something, too. 

The views don't have to be parallel or perpendicular to each other, because the object can be presented more accurately on a non-45 degree multiplicated plane

The object can be rotated, but the rotation must be marked with a proper arrow and a degree value. 

## Unfolded views

THey can represent a single plane with lines that symbolize the place where the fold exists. 

## Repeating elements

A few fragments can be drawn to represent a bigger amount of them. We can mark them with an arrow and x(amount) to represent a proper amount.
