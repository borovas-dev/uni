## Life of a product

1. [identifying a need -> conceptual design -> detail design] -> 2. [production -> use/operation -> recycling/disposal] 

1. Operations on abstracts
2. Operations pon concretes

Recycling = reusage

## Preparation

Let's say we need to prepare a cobblestone. We need to establish such parameters:

- material,
- dimensions,
- shape.

There is a certain difference between conceptual drawings and real implementation.

The difference between ideal and real size = tolerance.

The tolerance is needed for:
- establishing production limits
- defining whether the object fits within established limits

## Concept of design features

- geometrical design features (external structure)
- material design features (internal structure)
- dynamic design features (determines the state of the product induced during the material's assembly)

### Detail design 

Design is a "recipe" for the correct execution (or realization) of the product
